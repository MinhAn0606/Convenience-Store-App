# Convenience-Store-App

Dự án gồm `frontend/` (web React/Vite hiện có), `backend/` (Express/MongoDB dùng chung) và `mobile/` (React Native Expo JavaScript).

- [Hướng dẫn cài đặt, chạy và kiểm thử](docs/development.md)
- [Kiến trúc](docs/architecture.md)
- [Hợp đồng API](docs/api-contract.md)
- [Bảo toàn source và migration](docs/migration-plan.md)
- [README gốc của dự án web](docs/ORIGINAL-README.md)

Mobile có đăng nhập, đăng ký, đăng xuất, sản phẩm, chi tiết sản phẩm, giỏ hàng, checkout nhận tại cửa hàng, đơn hàng/lịch sử và hồ sơ cá nhân. Một số module ngoài phạm vi này của web/backend vẫn đang phát triển.
